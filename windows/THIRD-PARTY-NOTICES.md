# Windows distribution: licenses and third-party notices

The original FormatWheel project by Elise616 is MIT-licensed; its copyright and license remain in the repository's `LICENSE` and the packaged `LICENSE-MIT.txt`.

The Windows package includes **PyMuPDF/MuPDF under GNU AGPLv3**. The combined Windows application is distributed under AGPLv3 terms, with `LICENSE-AGPL-3.0.txt` and matching FormatWheel sources/build scripts in `FormatWheel-Windows-Source.zip`. This does not replace the original MIT grant for upstream source files. PyMuPDF's license choices are documented by [Artifex/PyMuPDF](https://pymupdf.readthedocs.io/en/latest/about.html#license-and-copyright).

## Bundled components

Exact runtime, build and transitive package versions are pinned in `requirements-lock.txt`. The packager copies available license, copying and notice files from installed distributions into the application's `licenses/` folder, including notices for transitive dependencies. Those component-specific texts and copyright statements accompany the distribution; this table is a guide to the principal components, not a replacement for their licenses.

PDF outputs retain a fixed PyMuPDF/MuPDF (Artifex) producer attribution, including privacy-cleaned outputs; personal source producer information is removed.

The portable/installed application keeps Qt libraries as separate files in its directory, so users can replace the libraries with compatible builds. The matching application source archive and build scripts support rebuilding the application. Preserve these notices and the included dependency license files when redistributing a build.

## Separately installed tools and models

`Install-Dependencies.ps1` can obtain the following components. They are separate installations/downloads, with their own licenses and source distributions:

| Component | License/source information |
| --- | --- |
| FFmpeg / ffprobe | LGPL/GPL configuration depends on the installed build; [FFmpeg licensing](https://ffmpeg.org/legal.html), [source](https://ffmpeg.org/download.html#get-sources). This port uses encoders such as libx264/libx265 when available. |
| LibreOffice | [MPLv2 and other included component licenses](https://www.libreoffice.org/about-us/licenses/), [source](https://www.libreoffice.org/download/download-libreoffice/) |
| Tesseract OCR and `tessdata_fast` language files | [Tesseract Apache-2.0/source](https://github.com/tesseract-ocr/tesseract), [language data/source](https://github.com/tesseract-ocr/tessdata_fast/tree/4.1.0) |
| U²-Net / `u2netp.onnx` | [U²-Net project and Apache-2.0 license](https://github.com/xuebinqin/U-2-Net); [rembg model distribution](https://github.com/danielgatis/rembg/releases/tag/v0.0.0). Model weights are separate artifacts from rembg's MIT-licensed Python code. |

No Apple system frameworks, Apple fonts or third-party game assets are bundled. FormatWheel's application artwork and sound effects are generated by code. The upstream promotional video and its music are not part of the Windows application package.
